엄마 가게 쇼핑몰을 AI랑 하루 만에 만든 이야기 (천왕봉 죽염)

지리산 천왕봉 아래 산청에서 엄마가 죽염을 만드신다. 대나무 통에 천일염을 담아 황토로 막고, 소나무 장작불에 아홉 번 굽는 죽염이다. 그동안은 전화나 다른 쇼핑몰로만 팔았는데, 엄마 선물로 우리 가게만의 쇼핑몰을 만들어 드리고 싶었다. 코딩은 거의 모르지만, Claude Code(AI 코딩 도우미)한테 말로 설명하면서 만들었다. 나중에 다시 볼 수 있게 과정을 정리해 둔다.

완성된 주소: www.천왕봉죽염.kr

사용한 서비스

Claude Code코드를 전부 짜 준 AI. 클라우드 세션에서 채팅으로 요청했다.
GitHub사이트 코드를 보관하는 곳.
Vercel사이트를 인터넷에 띄워 주는 곳. 코드를 올리면 1~2분 뒤 자동으로 반영된다.
Supabase회원가입·로그인, 상품·주문·후기를 저장하는 데이터베이스.
토스페이먼츠카드·간편결제. 소규모 개인사업자도 신청할 수 있다.
호스팅케이알한글 도메인(천왕봉죽염.kr) 구입.
네이버 클라우드오시는 길 페이지의 네이버 지도.

1. 뼈대 만들기

"엄마 가게 천왕봉 죽염 쇼핑몰을 만들고 싶다. 카드결제, 장바구니, 회원가입 다 되게"라고 요청하는 것부터 시작했다. 상품 목록, 상품 상세, 장바구니, 회원가입·로그인, 주문·결제, 내 주문 내역, 그리고 엄마가 쓰실 관리자 화면까지 한 번에 나왔다. 엄마 이메일로 가입하면 자동으로 관리자가 되게 해 달라고 했다.

Supabase 프로젝트를 만들고, Vercel에 사이트를 올리고, 필요한 열쇠(키)들을 Vercel 환경변수에 넣었다. 어디에 뭘 넣는지 몰라서 캡처를 찍어 보여주면서 물어봤다.

팁. 비밀 키(Supabase service role 키, 토스 시크릿 키)는 채팅에 붙여넣지 말고 Vercel 환경변수 칸에 직접 넣었다. 코드에도 안 들어간다.

2. 디자인은 광고 영상에서

예전에 만들어 둔 죽염 광고 영상을 보여주고 "이 느낌으로 전체 컨셉을 잡아 달라"고 했다. 한지 빛 바탕, 먹 글씨, 붉은 낙관, 대나무와 산 그림이 들어간 수묵화 느낌으로 바뀌었다. 영상 속 붓글씨 로고도 잘라서 썼다.

3. 쇼핑몰이라면 꼭 있어야 하는 것들

  • 사업자 정보: 대표자, 사업자등록번호, 주소, 전화번호를 아래쪽에 표시. 통신판매업 신고번호는 신고증에 적힌 번호를 그대로 넣었다. 공정위 사업자정보확인 링크도 달았다.
  • 이용약관·개인정보처리방침·교환/환불 정책 페이지. 토스 심사할 때 환불정책 주소를 따로 적어야 했다. 예전에 쓰던 환불 정책을 참고로 주고 택배비(편도 4,000원, 왕복 8,000원)에 맞게 고쳤다.
  • 배송비: 4,000원, 5만 원 이상 무료배송.
  • 비회원 주문: 어르신 손님은 가입을 번거로워하셔서, 주문번호와 전화번호로 주문 조회가 되게 했다.
  • 무통장입금: 기능은 만들어 두고 일단 꺼 뒀다. 토스 가상계좌와 둘 중 뭘 쓸지 정하면 켤 예정.
  • 용량 옵션: 같은 죽염도 80g, 250g, 1kg처럼 용량별로 값과 재고가 따로다.

4. 결제 테스트에서 배운 것

토스 테스트 결제를 해 보니 카카오페이, KB페이 창이 뜨면서 계속 결제하라고 나왔다. 테스트 모드에서는 원래 그렇고, 실제 돈은 안 나간다. 끝까지 진행하니 내 주문에 "결제완료"로 잘 찍혔다.

테스트하다가 가상계좌로 결제하면 돈이 들어오기도 전에 "결제완료"가 되는 문제를 발견했다. 바로 고쳐서 이제는 "입금 대기"로 있다가, 입금되면 토스가 알려줘서 결제완료로 바뀐다. 비회원으로도 실제 결제를 한 번 해 보고, 금액과 재고가 맞게 줄어드는지 확인했다.

5. 실제 상품 넣기

가격표 사진과 상품 설명을 정리해서 주니 상품 16개가 한 번에 등록됐다. 재고는 전부 100개로 시작. 상품 사진은 엄마가 관리자 화면에서 직접 올리고 계신다.

주의. AI가 상품 설명 중 일부 문구를 스스로 판단해서 뺐다. 이미 쓰고 있는 문구라서 원래대로 되돌려 달라고 했다. 기존 글은 "바꾸지 말고, 걱정되는 점만 알려 달라"고 미리 말해 두는 게 좋다.

6. 영상, 앱 설치, 공유 미리보기

  • 광고 영상 3편을 메인 화면에 넣었다. 영상 끝의 다른 쇼핑몰 안내 문구는 내가 직접 지운 버전으로 바꿨다.
  • 휴대폰 홈 화면에 앱처럼 설치할 수 있게 했다. 아이폰은 설치 방법 안내가 뜬다.
  • 카톡으로 주소를 보내면 사진과 설명이 예쁘게 뜨게 했다(OG 미리보기). 네이버·구글 검색 로봇도 상품 정보를 읽을 수 있게 했다.
  • 메인의 소개 사진은 영상 캡처 대신 실제 선물세트 사진으로 바꿨다.

7. 후기와 오시는 길

  • 구매 후기: 실제로 산 사람만 별점과 사진 후기를 쓸 수 있다. 이름은 "박*엽"처럼 가려진다. 관리자는 후기를 숨길 수 있다.
  • 오시는 길: 페이지 안에서 바로 지도가 보이게 했다. 메뉴 맨 끝에 두고, 장바구니는 아이콘으로 바꿨다.

8. 도메인 연결: www.천왕봉죽염.kr

처음 주소는 jukyeom-shop-eta.vercel.app 이라서 알려주기 어려웠다. 호스팅케이알에서 천왕봉죽염.kr을 사고, Vercel에 도메인을 추가한 뒤 호스팅케이알 DNS 설정에 Vercel이 알려준 값을 넣었다. 연결된 뒤에는 옛 주소로 들어와도 새 주소로 자동으로 넘어가게 했다. Supabase 로그인 설정의 사이트 주소도 새 주소로 바꿨다.

한글 도메인 팁. 한글 주소는 컴퓨터가 쓰는 영문 주소가 따로 있다. 천왕봉죽염.kr은 xn--9n3bs7nuhy7gm6f.kr이다. 한글이 안 받아지는 곳에는 이걸 넣으면 된다. 다만 네이버 클라우드 지도 설정은 이 영문 주소도 받아주지 않아서 아직 해결 중이다.

9. 검색에 나오게 하기

  1. 구글 서치콘솔에 "URL 접두어"로 사이트를 등록하고, 받은 확인 파일을 사이트에 올려서 소유 확인.
  2. 네이버 서치어드바이저에 사이트를 등록하고, 받은 확인 코드(meta 태그)를 사이트에 넣어서 소유 확인.
  3. 두 곳 모두 사이트맵(sitemap.xml) 제출.
  4. 네이버 스마트플레이스에 가게 등록 (검토 최대 5일).

실제로 검색에 뜨기까지는 며칠에서 2~3주 걸린다고 한다.

해 보니

하루 동안 요청하고, 캡처 보내고, 고쳐 달라고 하기를 반복했더니 쇼핑몰이 됐다. 제일 오래 걸린 건 코드가 아니라 사업자 정보, 결제 심사, 도메인, 지도처럼 사람이 직접 신청하고 기다려야 하는 일들이었다. 남은 건 토스 결제 심사가 끝나는 것. 엄마가 좋아하셨으면 좋겠다.
